Retail Sales Analytics is an end-to-end project using Excel, SQL, Python, and Power BI for data cleaning, SQL analysis, EDA, RFM analysis, customer segmentation, and interactive dashboard creation.
Retail Sales Analytics

An end-to-end data analytics project using Excel, SQL, Python, and Power BI.

Tools Used

* Excel – Data Cleaning
* SQL – Data Analysis
* Python – EDA & Customer Segmentation
* Power BI – Interactive Dashboard

Project Focus

* Sales Analysis
* Customer Analysis
* Customer Segmentation
* Product & Store Performance
* Interactive Dashboard.
